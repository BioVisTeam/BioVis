# BioVis · Chronic disease and social vulnerability

CDC PLACES (2025 release), CDC/ATSDR SVI (2022) and Census boundaries. Course project for Information Visualization (Team 15).
All questions ask about association, not cause. National views use counties; tract views are only for NYC.

## Milestone 2 — Q1/Q2

National county variation (Q1) and NYC within-county variation (Q2): processed tables, matplotlib sketches, reproduction steps and checks:
[Q1/Q2 documentation](docs/README_q1_q2.md). Everything runs from the files in this repo (`pip install -r requirements_q1_q2.txt`).

## Milestone 2 — Q3/Q4

County SVI/disease transformations, executed notebook, static data tables, sources, validation and AI disclosure: [Q3/Q4 documentation](docs/README_q3_q4.md).

Open [the executed transformation notebook](notebooks/q3_q4_transformation.ipynb) in [Google Colab](https://colab.research.google.com/github/BioVisTeam/BioVis/blob/milestone2-q3-q4-20261103-051227/notebooks/q3_q4_transformation.ipynb).

## Milestone 2 — Q5/Q6

Tract-level views from PLACES 2025 and SVI 2022. Q5 asks whether the NYC tracts with the highest prevalence also have the most affected residents. Q6 asks how the set of high-priority tracts across the US changes with the criterion (prevalence, affected population, social vulnerability) and the threshold. Initial data tables, sources, validation and AI disclosure: [Q5/Q6 documentation](docs/README_q5_q6.md).

Open [the transformation notebook](notebooks/q5_q6_transformation.ipynb) in [Google Colab](https://colab.research.google.com/github/BioVisTeam/BioVis/blob/BRANCH_NAME/notebooks/Question5&6(Transformation&EDA).ipynb).
